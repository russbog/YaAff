# Фаза 7: Отчётность — real-time дашборд, графики и экспорт по расписанию

Фаза 7 добавляет живое операционное представление поверх существующей статистики
с сохранёнными таблицами (`admin/statistics.php`): **real-time дашборд** с
KPI-карточками и графиком во времени, а также **универсальный экспортер отчётов**
(настраивается данными), пригодный для запуска по cron в форматах CSV/JSON. Лог
конверсий и постбэков уже есть на странице **Conversions** (Фаза 3); дашборд
дополняет их агрегированными авто-обновляемыми метриками.

## Компоненты

### `reports/ReportAggregator.php` (чистый)
Вычисляет KPI из сырых базовых счётчиков. Без I/O — полностью покрыт тестами,
переиспользуется дашбордом, экспортером и (позже) REST API.

- `metrics(array $base): array` → объединяет базовые счётчики с производными
  `profit`, `roi`, `cr`, `epc`, `cpc`, `uniques_ratio`, `bot_ratio`.
  Все деления безопасны к нулю.
- `mergeSeries(array $clickBuckets, array $convBuckets): array` → сливает
  ряды кликов и конверсий в один упорядоченный ряд с заполнением пропусков нулями.

### `reports/DashboardQuery.php`
Живые запросы, отделённые от большого класса `Db`, чтобы работать с любым
`DbDriver` (сейчас SQLite, позже MySQL) и тестироваться на засеянном драйвере.
`campId = 0` означает *все кампании*.

- `summary($campId, $start, $end)` → клики/уники/расход (из `clicks`),
  заблокированные/боты (из `blocked`, `reason = 'bot'`), конверсии/доход/лиды/
  продажи/реджекты (из `conversions`), пропущенные через `ReportAggregator`.
- `timeseries($campId, $start, $end, $tzOffset)` → суточные корзины через
  `DbDriver::dateGroup` (с учётом часового пояса), слитые `mergeSeries`.
- `topBy($field, $campId, $start, $end, $limit)` → топ-разбивка по разрешённому
  измерению клика (`country`, `isp`, `os`, `device`, `flow`, …). Неизвестные
  поля возвращают `[]` (нет поверхности для SQL-инъекций).

### `reports/ReportExporter.php` (чистый)
Помощники сериализации, без I/O.

- `flattenTree($tree, $groupBy)` → разворачивает вложенное дерево из
  `Db::get_statistics` в плоские строки, перенося каждый уровень группировки в
  колонку.
- `toCsv($rows, $columns = null)` → CSV в духе RFC-4180 (экранирует `" , \r \n`).
- `toJson($rows)` → компактный JSON.

## UI дашборда

`admin/dashboard.php` (навигация: **Dashboard**) рисует KPI-карточки, график-линию
на чистом `<canvas>` без сторонних библиотек (Клики против Конверсий) и таблицы
Топ стран / Топ потоков. Страница опрашивает `dashboard.php?action=data` с часовым
поясом браузера, фильтром по кампании, выбором периода (1ч / 24ч / 7д / 30д) и
настраиваемым интервалом авто-обновления. График рисуется на обычном `<canvas>` —
без внешних библиотек графиков и CDN.

JSON-эндпоинт:

```
GET admin/dashboard.php?action=data&campId=<id>&start=<ts>&end=<ts>&tz=<IANA tz>
→ { summary:{...}, series:[...], top_country:[...], top_flow:[...] }
```

## Экспорт по расписанию / CLI

`bin/export_report.php` — универсальная точка входа экспорта для cron,
настраиваемая данными.

```bash
php bin/export_report.php path/to/report.json [output/path]
```

Конфиг отчёта (JSON, настраивается данными — добавить отчёт = правка конфига, не кода):

```json
{
  "name": "daily-geo",
  "campaign_id": 12,
  "timezone": "UTC",
  "range": "today",
  "fields": ["clicks", "uniques", "conversion", "revenue", "profit"],
  "group_by": ["date", "country"],
  "format": "csv",
  "output": "exports/{name}-{date}.csv"
}
```

- `range`: `today` | `yesterday` | `7d` | `30d` | `<секунды>`.
- Токены `output`: `{name}`, `{date}`, `{ts}`. Без `output` пишет в STDOUT.
- `group_by` переиспользует движок сохранённых таблиц (`Db::get_statistics`),
  поэтому доступна любая колонка или JSON-ключ `param.*`, что поддерживает статистика.

Отчёты формируются **по кампании** (`campaign_id`), как и в движке статистики.
Доставка (email/webhook) и планирование намеренно оставлены планировщику Фазы 8 и
уведомлениям Фазы 9, которые оборачивают этот универсальный экспортер.

Пример cron (ежечасно):

```
0 * * * * php /path/to/YellowTDS/bin/export_report.php /path/to/report.json
```
