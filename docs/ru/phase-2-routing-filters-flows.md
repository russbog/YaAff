# Фаза 2: Режимы трекинга, расширенные фильтры и типы потоков

Фаза 2 доводит движок маршрутизации, набор фильтров и модель потоков до
паритета с Keitaro. Всё настраивается данными и обратно совместимо:
существующие кампании работают без изменений (числовые коды редиректа, текущие
фильтры, безымянные потоки).

## 2.1 Единые режимы редиректа

На уровне шага / оффера / лендинга доступен единый enum режимов редиректа.
Режимы рендерит `redirects/RedirectStrategy.php`, диспетчеризация — в
`redirect.php` / `actions.php`.

| Режим | Тип | Описание |
|-------|-----|----------|
| `http_301` / `http_302` / `http_307` | сервер | HTTP-редирект `Location` с заданным кодом |
| `http_404` | сервер | Возвращает 404 Not Found |
| `js` | клиент | Редирект через `window.location` (инлайн-скрипт) |
| `meta` | клиент | Редирект через `<meta http-equiv="refresh">` |
| `double_meta` | клиент | Двойной meta-refresh со сбросом реферера |
| `blank_referrer` | клиент | Meta-refresh с `referrer=no-referrer` |
| `formsubmit` | клиент | Автоотправка POST-формы (передаёт POST-данные) |
| `iframe` | клиент | Встраивает цель в полноэкранный iframe |
| `curl` | сервер | Серверное cURL-проксирование (без редиректа) |
| `remote` | сервер | Удалённый reverse-proxy |
| `inline` | контент | Инлайн HTML-контент |
| `custom_json` | контент | Произвольное тело с настраиваемым `Content-Type` |

Обратная совместимость: числовые коды (`301/302/303/307`) по-прежнему
принимаются везде и нормализуются через `RedirectStrategy::normalizeMode()`.
Сохранён и legacy-возврат строки для режима `js`, используемый в `send.php`.

## 2.2 Расширенные фильтры (уровень Keitaro)

Новые типы фильтров доступны в query-builder AND/OR (панель фильтров в админке),
реализованы в `core.php` с чистыми хелперами в `filters/FilterFunctions.php`:

- **region, city** — гео-точный таргетинг (требует `GeoLite2-City.mmdb`).
- **connection_type** — тип соединения из данных GeoIP ISP/ASN.
- **search_engine** — определяется по рефереру через таблицу данных
  `bases/searchengines.json` (паттерны хостов + параметры ключевых слов),
  без хардкода.
- **keyword** — поисковый запрос из query-строки реферера.
- **site** — хост реферера.
- **creative_id, x_requested_with** — дополнительные параметры кампании / заголовка.
- **timetable** — дни недели + диапазоны часов с таймзоной, напр.
  `[{"days":[1,2,3,4,5],"from":9,"to":18}]` (1=Пн..7=Вс).
- **date_between** — диапазон дат `from,to` (`YYYY-MM-DD`).
- **click_limit** — лимиты кликов на поток: час / сутки / всего, напр.
  `{"window":"day","limit":1000}` (`window`: `hour|day|total`).
- **uniqueness** — уникальный или повторный клик (по userid/clickid в БД).
- **bot** — детект ботов как первоклассный фильтр (см. 2.3).
- **именованные параметры кампании** — `sub_id_1..30`, `keyword`, `creative_id`,
  `site` берутся из запроса с откатом к query-строке.

### Новые операторы сравнения

Помимо существующих операторов, сравнения теперь поддерживают:

- **маски** — `*` (любые символы) и `?` (один символ), напр. `promo_*`.
- **regex** — PCRE в разделителях `/pattern/`, напр. `/^utm_/i`.
- операторы `matches` / `not_matches` в query-builder применяют маску или regex
  автоматически в зависимости от значения.

## 2.3 Бот / VPN / proxy как фильтры query-builder

`bot` и `vpntor` (VPN/Tor/proxy) теперь обычные условия фильтра и комбинируются
с любым другим условием внутри AND/OR-конструктора, а не отдельные хардкод-тумблеры.
(Автообновляемые локальные базы IP-диапазонов — в Фазе 6.)

## 2.4 Типы потоков + ротация по весам

У потоков теперь есть **тип** и **вес** (`campaign.php`, `FlowSettings`; выбор —
`flow/FlowSelector.php`):

- **forced** — проверяются первыми, по порядку; первый подходящий forced-поток
  выигрывает безусловно.
- **regular** — подходящие regular-потоки участвуют во взвешенном случайном
  распределении.
- **default** — фолбэк; default-поток используется только если ни один regular
  не подошёл.

Порядок выбора: forced → regular (по весам) → default. Потоки без явного типа
по умолчанию `regular` с весом `100`, поэтому существующие кампании ведут себя
ровно как раньше.
